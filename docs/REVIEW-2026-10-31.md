# Source audit and documentation reconciliation — 2026-10-31

Scope: static inspection of repository `yishaik/Scorched` at `main` commit `26b9c8b`, current source game version **1.15**. Reviewed gameplay HTML/JS/CSS structure, WebSocket client/server, landing, Android manifest/Java/Gradle, packaging and deploy scripts, rendering scripts, marketing and existing documentation. Binary APK and PNG files were identified but **not decompiled or visually validated**. No local build, device test, runtime integration test or live production release was performed.

These are **review findings** rather than proof of production exploitation. Status for every row: **open / not fixed by this documentation PR**.

## Validated from source vs unverified

**Validated in code:** v1.15 constants in game/worker/landing; local setup persistence; save/continue; rotation-aware letterboxing; modern/classic renderer; map editor and decoration; Cloudflare Worker/DO multiplayer; client reconnection/host migration handlers.

**Not independently validated:** that the published domain currently serves v1.15, APK's actual bytecode/version/signature, build success in a clean checkout, behavioral correctness on devices, exploitability of trust issues in a real game, published Play Store listing, end-to-end matchmaking performance, coverage across all weapons/walls.

## Risk-based follow-up order

1. Make `build.sh` and signing predictable; add build provenance.
2. Establish root CI with static checks and syntax verification, then Android/browser/Worker tests.
3. Secure `pid` ownership and harden the room API/relay; validate economy.
4. Add staging and release verification before changing production.
5. Add gameplay and renderer regression suites; update capacity/features from test evidence.

This documentation-only review deliberately **does not repair code**, create a release, deploy to Cloudflare, or merge to `main`.
